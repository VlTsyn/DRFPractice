# Учебный проект от SkyPro

## Описание:

Практика с DjangoRestFramework

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/VlTsyn/DRFPractice.git
```
2. Установите зависимости:
```
python3 -m venv .venv
.venv\Scripts\activate
pip install poetry
poetry init
```
